# ALPHA-T samples generated in the cloud (2026-10-12)

Made with the vendor ALPHA-T V1.2 under DOSBox-X + Xvfb, driven by xkeys, on a scratch copy of `vendor/AlphaT`
(METRIC=1 MMETRIC=1, metric drawing and output). Check of the setup: MET2_finish_metric.PRG and AREA1_metric.PRG
were regenerated byte-identical to `re-notes/alphat_samples/`.

Base profile is MET2: X(dia) 0 -> 40 at Z0, 40 to Z-25, step to 60, 60 to Z-50, step to 100. Tool 3 (55 deg finisher
0.4R) unless noted. No offsets, no pre-finish.

Scripts: `scripts/gen_at.py NAME --pts ... [--rad "x,z:r"] [--ops "tool:1 area tool:3 finish"]` writes the .ks;
`scripts/start.sh` starts a fresh scratch session, `scripts/k.sh < file.ks` drives it (paths inside point at the
cloud scratchpad; adapt for local use). ALPHA-T saves into DRAWINGS\ under the typed name (xkeys drops 'A', so the
raw names were RCFIN, RCRGH, ...; renamed when copied here).

gen_at.py also takes `--start X,Z --seek Up:2` (internal start) and `--menu-area/--menu-finish` (keys in the options menu, e.g. offsets or the EXTERNAL->INTERNAL toggle).

Learnt: the 2nd CHANGE TOOL first asks "Tool Change Position [X100 Z50]" (Enter) before the picker; the picker
starts on the current tool. Contour pick needs one Enter per contour point, arc end points included.
