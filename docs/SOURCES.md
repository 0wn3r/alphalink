# Sources of the vendor software

The vendor software studied in this repo was published by Superdraft Systems as password-protected
self-extracting archives on www.superdraft.co.uk. That site is gone; the Internet Archive kept copies.
The links below point to the Wayback Machine's capture list for each file.

The files and the software inside them are Superdraft's copyright. They are **not** redistributed here, and
neither are their passwords. The SHA-256 column identifies the archives as downloaded; `VENDOR_FILES_SHA256.txt` identifies the extracted
files this work was based on.
